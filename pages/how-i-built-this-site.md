# How I built this site

## Creating my Website!

I created this website using GitHub Pages and Jekyll. The goal was to take the communication theories I explored in my Theory Primer and turn them into something that everyday readers could understand and apply to their own experiences.

Rather than presenting the information like a traditional research paper, I organized the website into different sections that explain communication theories and connect them to real-life examples involving generative AI.

Throughout the website, I focused on two examples: using AI to rewrite an apology to a friend and using AI to make a message to a coworker sound more professional.

## Agent involvement

AI played a role in developing this website. GitHub Copilot helped generate the original website structure, layout, and styling, including the navigation and placeholder pages.

I also used HokieAI to help brainstorm how to adapt my Theory Primer for a nonacademic audience, organize the website content, and troubleshoot formatting issues.

I reviewed and edited the suggested content to decide how I wanted to present the communication theories and examples.

**AI helped me build and organize this website, but I was responsible for deciding what I wanted it to communicate.**
