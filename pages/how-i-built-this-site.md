# How I built this site

This page documents the process behind the tool stack, layout, and content scaffolding.

The site is built with Jekyll for GitHub Pages, using an accessible layout, a Virginia Tech-inspired professional color system (maroon, orange, white, and gray), and reusable navigation so each section is easy to find.

## Agent involvement
